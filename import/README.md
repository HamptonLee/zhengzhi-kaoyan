# 答案导入说明

## 一、用表格（最稳）

`答案导入模板.csv` 已经按 497 道题排好，只需填两列：

| 列 | 填法 |
|---|---|
| 答案 | 单选填一个字母，如 `B`；多选填多个，如 `ABD`（大小写、顿号、逗号都行） |
| 讲解 | 随便写，支持多行（Excel 里 Alt+Enter 换行）；可以留空 |

其余列不要改，尤其 **题目ID**。

填完保存为 `.csv`（UTF-8）或 `.xlsx`，双击 `导入答案.bat`，把文件拖进去回车即可。

## 二、用文本 / Word / PDF

只要满足「题号锚点 + 答案 + 解析」的结构，就能识别：

```
2020-单选（2）十月革命之前，列宁总结当时变化了的新情况……
A.资本主义经济和政治发展不平衡规律
B.资本主义国家的不断衰落
C.科学社会主义理论的广泛传播
D.无产阶级力量的不断壮大
答案：A
解析：列宁在《论欧洲联邦口号》中提出……
```

- 题号锚点写法支持：`2020-单选（2）`、`2020-多选.(5)`、`2020.（4）`
- 答案写法支持：`答案：A`、`答案 A`、`【答案】ABD`
- 解析自动截取到下一题之前；没有解析也能只导答案
- PDF 需要先安装 pypdf：`python -m pip install pypdf`；扫描版无文字层，不识别

## 三、题号重复怎么办

源文档有 17 组题号重复（例如政治经济学·多选第 4 题，1998 年和 2010 年各一道）。用文本方式导入时会提示「命中 2 道」，这时改用表格，在 **题目ID** 列填精确值：

```
马克思主义哲学/政治经济学/多选/4        ← 1998 年
马克思主义哲学/政治经济学/多选/4@2010   ← 2010 年
```

题目 ID 的规则：`学科/部分/题型/题号`，重复的加 `@年份`。模板里已经写好，直接复制即可。

## 四、常见问题

- **导入后网页没变？** 刷新页面（Ctrl+F5）。`导入答案.bat` 会自动重建 `data/questions.js`。
- **手填的答案会被覆盖吗？** 不会，手填的标记为 `manual`，除非导入时加 `--force`。
- **想清空重来？** 删除 `data/answers.json` 后运行 `python build/build_data.py`。
